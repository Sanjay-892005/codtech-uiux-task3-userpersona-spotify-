# Spotify UI/UX Case Study

## Task 3: User Persona Development

### Project Overview
This task focuses on understanding Spotify users' goals, behaviours, needs, and pain points through user research and persona development.

### Research Participant
- **Name:** Thirumurugan
- **Age:** 21
- **Occupation:** College Student
- **Product:** Spotify

### Research Method
An informal user interview was conducted to understand the participant's music-listening habits, preferences, and challenges while using Spotify.

### Key Research Insight
The participant enjoys mixed-genre music and primarily listens to Spotify recommendations but finds frequent advertisements frustrating.

### User Persona Deliverable
A visual user persona board was created to summarize the participant's profile, goals, behaviours, pain points, and needs.

### Design Opportunity
Explore potential ways to make the music-listening experience less interrupted while maintaining convenient access to recommended music.

### Tools Used
- Google Stitch – AI-assisted persona board generation
- GitHub – Project documentation and image hosting

This is an independent UI/UX case-study exercise based on one participant. It is not affiliated with or endorsed by Spotify.
